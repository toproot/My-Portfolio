## 작성 원칙

- 경력·성과·기술은 이력서에서 확인된 내용만 사용한다.
- 팀 프로젝트의 지표는 개인 단독 성과로 단정하지 않고 “프로젝트 결과”로 표현한다.
- `주도`, `리딩`, `설계` 같은 표현은 이력서 원문에 해당 역할이 명시된 항목에서만 사용한다.
- 숙련도 퍼센트·별점, 적합도 점수, 채용 추천 등급은 만들지 않는다.
- 생년, 성별, 휴대폰, 상세 주소는 게시 데이터·메타데이터·다운로드 파일에 포함하지 않는다.
- 원본 이력서 PDF는 공개하지 않는다.
